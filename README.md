# 오늘의 실천 (가칭) · MVP 1차

작은 실천을 기록하면 숲이 자라는 생태 실천 모바일 웹앱(PWA)입니다.

- 기획안: [노션 기획안](https://hushed-mollusk-6a1.notion.site/3f5ef6711c3c81cab4dbfe3bd13a63d0)
- 디자인 기준: [핵심 화면 목업](https://claude.ai/artifact/1QLA72dHdco7JX2311uFVz) (원본 사본은 `mockup/project/`)

## 실행

ES 모듈과 서비스 워커를 쓰므로 `index.html`을 파일로 직접 열면 동작하지 않습니다. 로컬 서버로 여세요.

```bash
python -m http.server 8765
# http://localhost:8765
```

- 발표 시연용: `http://localhost:8765/?demo=1#/forest` 로 열면 숲 화면에 점수 버튼이 나옵니다.
- 휴대폰으로 확인하려면 같은 와이파이에서 `python -m http.server 8765 --bind 0.0.0.0` 후 PC의 IP로 접속합니다. 단, 홈 화면 설치와 서비스 워커는 HTTPS(또는 localhost)에서만 동작합니다.

## 배포

GitHub 저장소(hey-bernard/eco-practice)의 `main`에 push하면 Vercel이 자동으로 운영 배포한다. 다른 브랜치에 push하면 미리보기 주소가 따로 만들어진다.

## 학생용 · 성인용

첫 실행에서 **학생(중학생)** 또는 **성인**을 고르면 그에 맞는 버전으로 들어간다. 기록 화면 맨 아래 '대상 바꾸기'로 다시 고를 수 있다.

| | 학생용 | 성인용 |
| --- | --- | --- |
| 하단 메뉴 | 미션 · 기록 · 우리 반 · 배우기 | 오늘 · 기록 · 모임 · 읽기 |
| 카드 | 학교·집·등하굣길 미션 25개 (장소 태그) | 생활 실천 카드 30개 |
| 함께하기 | 우리 반 (반 숲, 공동 미션, 정해진 응원만) | 지역·온라인 모임, 모임장 승인 AI 후기 |
| 읽기 | 같은 원문 + 학생용 '생각 한 줄' 질문, 뉴스레터 없음 | 성찰 질문 + 뉴스레터 |
| 로그인 | 학급 코드 + 닉네임 (화면만) | 카카오·구글 (화면만) |
| 지구 마을 | 있음 | 없음 |

- 기록은 대상별로 따로 저장한다 (`eco-practice-student-v1` / 성인은 기존 `eco-practice-v1`).
- 발표 때 두 버전을 바로 보여 주려면 주소에 `?as=student` 또는 `?as=adult`를 붙인다. 저장된 선택보다 먼저 적용된다.

## Stitch 디자인 버전 (`/stitch/`)

Google Stitch(프로젝트 '오늘의 실천 – Stitch 버전')로 만든 시안을 입힌 두 번째 디자인. 기능과 화면 구성은 원래 버전과 같다.

- 주소: `/stitch/` (예: `/stitch/?as=student#/today`). 원래 버전 기록 화면 맨 아래에서도 들어갈 수 있다.
- `stitch/app.js`가 화면만 새로 그리고, 데이터·저장·대상 선택은 `js/data.js`, `js/store.js`, `js/audience.js`, `js/village.js`를 그대로 쓴다. 그래서 같은 기기에서는 두 디자인의 기록과 대상 선택이 함께 간다.
- 디자인 토큰(색·글꼴·모서리)은 Stitch가 만든 디자인 시스템 'Mindful Habit Companion'에서 옮겨 `stitch/index.html`의 Tailwind 설정에 둔다. 아이콘은 Material Symbols.
- Stitch 시안에 있던 '연속 실천 N일' 표시는 기록이 끊겨도 탓하지 않는다는 원칙에 맞지 않아 넣지 않았다.

## 기후 모니터 버전 (`/monitor/`)

Stitch 샘플 코드 '지구 기후 모니터 · Action Guide'(다크 배경, 네온 초록, Space Grotesk·Inter·JetBrains Mono)를 입힌 세 번째 디자인.

- 주소: `/monitor/` (예: `/monitor/?as=adult#/today`). 세 버전의 기록 화면 맨 아래에서 서로 오갈 수 있다.
- `monitor/app.js`는 `stitch/app.js`를 바탕으로 했다. 다크 색은 `monitor/index.html`의 Tailwind 설정에서 **같은 토큰 이름에 다크 값**을 넣어 바꿨다. 그래서 대부분의 화면은 Stitch 버전과 구성이 같다.
- 오늘 화면만 샘플처럼 대시보드로 바꿨다: 실천 트래커(오늘 기록 수 + 숲 다음 단계까지 원형 게이지), 분야 알약 필터, 카드별 이번 달 횟수, 반·모임 미션 배너, 이번 주 읽기.
- 샘플에 있던 등급(A+), 전국 평균 비교, 연속 실천 일수, 탄소 상쇄 구매는 넣지 않았다. 근거 없는 수치이거나 '탓하지 않기'·'순위 없음' 원칙에 맞지 않기 때문이다.

## 기후 홈 버전 (`/climate/`)

Stitch 샘플 'Climate Home'(같은 다크 디자인 시스템의 기후 지표 화면)을 참고한 네 번째 디자인. 하단 메뉴 맨 앞에 **지구** 탭을 더해 5칸이며, 주소만 열면 지구 탭부터 보인다.

- 지구 탭: 지구 평균기온과 1.5℃까지 남은 폭, 대기 중 CO₂, 남은 탄소 예산, 해수면·해수 표면온도, 내가 만든 변화(나의 숲·이번 달 기록), '그래서 오늘 할 수 있는 것'(오늘 카드·이번 주 읽기).
- 수치는 `climate/app.js`의 `CLIMATE` 한곳에 모았고, 모두 출처가 있는 발표 값이다 (WMO 2025년 기준, NOAA 2025년 2월 월평균, IGCC 2024의 2025년 초 탄소 예산 130 GtCO₂). 새 보고서가 나오면 여기만 고친다.
- 샘플의 'LIVE·NASA NOAA SYNC', 북극 +3.8℃, 예산 고갈 '2029년 11월', 극한 기후 3.2배, 외부 사진은 출처를 확인할 수 없거나 실시간이 아니어서 넣지 않았다. 겁주기보다 '아직 늦지 않았다'는 쪽으로 문구를 맞췄다.
- 나머지 화면은 기후 모니터 버전과 같다. 읽기 화면의 '기후 4대 지표'는 지구 탭으로 옮겼다.

## iOS 스타일 버전 (`/apple/`)

Apple Human Interface Guidelines를 따라 UX를 바꾼 다섯 번째 디자인. Claude Code의 `apple-design` 스킬로 만들었다.

- 주소: `/apple/` (예: `/apple/?as=adult#/today`). 시스템 설정에 따라 라이트·다크가 저절로 바뀐다.
- 오늘 화면: 카드 대신 **묶음 목록**. '미리 알림' 앱처럼 동그라미를 눌러 기록하고, 맨 위 **활동 링**이 오늘 진행을 보여 준다. 숲·마을·아낀 컵·모임·이번 주 질문도 색 아이콘 타일이 달린 목록 줄로 정리했다.
- 카드 더 고르기: 아래에서 올라오는 **시트**(손잡이, 왼쪽 '취소'), 분야별 묶음 목록, 이미 고른 카드는 체크 표시.
- 하단 **탭 막대**: 반투명 재질, 지금 탭만 틴트 초록 + 채운 아이콘. 화면 위는 **큰 제목**이고, 스크롤하면 위 막대에 작은 제목이 나타난다.
- 알림은 아래 토스트 대신 가운데 **HUD**. 누르면 튀지 않고 살짝 흐려진다. 움직임 줄이기 설정을 따른다.
- 글꼴은 시스템 글꼴(아이폰에서는 SF·Apple SD 산돌고딕), 본문 17px. 틴트는 흰 바탕에서도 읽히는 접근성 초록 `#248A3D`(다크 `#30D158`).
- SF Symbols와 SF 글꼴 파일은 웹에서 쓸 수 없어 Material Symbols Rounded와 시스템 글꼴로 대신했다. Apple 로고·기기 테두리는 넣지 않는다.
- 색은 `apple/style.css`의 CSS 변수에 있고, `apple/index.html`의 Tailwind 설정은 Stitch 버전과 같은 토큰 이름이 이 변수를 가리키게 했다. 그래서 기록·숲·읽기·모임 화면은 구성은 같고 iOS 색과 글자만 입었다.

## Material 3 버전 (`/material/`)

구글 Material Design 3(Material You)를 따른 여섯 번째 디자인. 안드로이드 휴대폰을 쓰는 사람에게 익숙한 모양.

- 주소: `/material/` (예: `/material/?as=student#/today`). 시스템 설정에 따라 라이트·다크가 바뀐다.
- 색: 초록 기준 색에서 뽑은 M3 색 역할(primary, secondary-container, tertiary-container, surface-container 단계 등). `material/style.css`의 `--md-*` 변수에 라이트·다크 값이 있고, Tailwind 설정이 같은 이름으로 가리킨다. Stitch 버전의 토큰 이름이 원래 M3 역할 이름이라 다른 화면도 그대로 M3 색을 입는다.
- 오늘 화면: 원형 진행 표시가 있는 요약 카드, 아이콘·두 줄 글·체크박스가 있는 목록 항목, 숲(올린 카드)과 아낀 컵(채운 카드) 두 칸, 모임·반 소식(윤곽 카드), 이번 주 질문. '카드 더 고르기'는 오른쪽 아래 **확장 FAB**.
- 위 **앱 막대**(왼쪽 제목, 오른쪽 계정 아이콘, 스크롤하면 바탕색이 짙어짐), 아래 **내비게이션 막대**(지금 탭 아이콘 뒤 알약 표시), 카드 고르기는 **아래 시트**(끌개, 분야별 목록), 알림은 아래 **스낵바**, 읽기 보기 전환은 **분할 버튼**.
- 누르면 상태 레이어가 덮이고 누른 자리에서 물결이 퍼진다(움직임 줄이기 설정이면 물결 없음). 글꼴은 Roboto + Noto Sans KR, 아이콘은 Material Symbols.

## LINE 스타일 버전 (`/line/`)

`line-design-system.md`(LINE Design System for Global Family Service, LDSG) 명세를 적용한 일곱 번째 디자인.

- 주소: `/line/` (예: `/line/?as=adult#/today`).
- 색: LINE Green·검정·11단 회색만 쓴다. LINE Green(#06C755)은 체크·진행 막대·아이콘 채움에, 흰 글자가 올라가는 버튼은 대비 3:1을 넘는 brand-primary-alt(#04A647)로 칠했다. 글자는 검정, 보조 글자는 흰 바탕에서도 읽히는 gray-600·700.
- 모양: 버튼 5px, 카드 7px(흰 블록 + 테두리 없음 + 흰 바탕용 그림자), 시트 12px, 칩은 알약. 그림자는 놓이는 바탕(흰색/연회색)에 맞춰 고른다.
- 상태: 색을 바꾸지 않고 불투명도만 (누름 50%, PC 호버 70%).
- 오늘 화면: 메신저 홈처럼 흰 블록을 8px 연회색 띠로 나눴다. 맨 위 나의 숲 프로필 줄, 오늘 실천 목록(원형 아이콘 · 오른쪽 원형 체크), 아낀 컵, 모임·반 소식, 이번 주 질문. '카드 더 고르기'는 아래 가운데 흰 **알약 떠 있는 버튼**.
- 아래 탭은 흰 바탕에 선택 = 검정 채운 아이콘·검정 글자, 기본 = gray-600 윤곽. 카드 고르기는 끌개와 닫기(X)만 있는 **아래 시트**, 알림은 검정 80% **토스트**(약 4초 뒤 저절로 사라짐), 읽기 보기 전환은 **밑줄 탭**, 주제는 **칩**.
- 글꼴은 명세 권장대로 LINE Seed KR(기기에 있으면) → Pretendard. 아이콘은 LAICON이 공개되지 않아 Material Symbols Rounded로 대신했다.
- 명세에 따라 다크 모드는 없다(LDSG에 다크 토큰이 없음). 화면 제목·버튼에는 디자인 시스템 이름을 넣지 않고, 다른 버전에서 오는 링크에만 'LINE 스타일'로 적었다. UI 알림 문구의 느낌표는 뺐다(캐릭터 대사는 그대로).

## 기후 4대 지표 그래프

모든 버전의 읽기(학생용은 배우기) 화면에 있던 '기후 4대 지표' 숫자 네 칸을 연도별 추이 그래프로 바꿨다. 기후 홈 버전은 지구 탭의 '연도별 추이'에 있다.

| 지표 | 기간 | 기준 | 원자료 |
| --- | --- | --- | --- |
| 지구 평균기온 편차 | 1850–2025 | 1850–1900년 평균 대비 | Met Office HadCRUT5.1 연평균 |
| 해수면 | 1993–2024 | 1993년 = 0 (cm) | NOAA Laboratory for Satellite Altimetry, 계절 신호 제거 |
| 해수 표면온도 편차 | 1850–2025 | 1981–2010년 평균 대비 | NOAA Climate at a Glance 전 지구 바다 월값의 연평균 |
| 대기 중 CO₂ | 1959–2025 | ppm | NOAA 마우나로아 연평균 |

- 그래프 하나에 지표 하나(눈금이 다른 값을 한 축에 겹치지 않음). 위에 최근 값과 첫해 대비 변화, 기온 그래프에는 파리협정 1.5℃ 가로선.
- 그래프를 누르거나 마우스를 올리면 가장 가까운 해의 값이 뜬다. 키보드는 그래프에 초점을 둔 뒤 좌우 화살표. '전체 기간 / 최근 30년'으로 네 그래프의 기간을 함께 바꾸고, '표로 보기'에 모든 값이 있다.
- 해가 끝나지 않은 해(예: 2026년)는 넣지 않았다. WMO 발표값(예: 기온 +1.44℃)은 여러 자료의 평균이라 그래프 값(HadCRUT5 +1.41℃)과 조금 다르다.
- 선 색은 버전마다 그 디자인의 초록에서 골랐고, dataviz 팔레트 검증기(명도·채도·바탕 대비)를 통과한 값을 썼다.
- 새 해 자료가 나오면 원자료를 다시 내려받아 `js/climate-data.js`를 다시 만든다(파일 맨 위 주석에 자료와 기준이 있다).

## 임시로 정한 값 (파일럿 데이터로 조정)

- 숲 점수: 실천 기록 1개 = 1점, 단계 기준 0·5·15·30·60·120점 (목업 값)
- 40일 챌린지 시작일: 첫 기록한 날
- 이번 주 성찰 질문과 카드: 연중 주차마다 14편을 차례로 순환
- 동물 해금: 새 = '오늘의 자연 한 줄' 3회, 다람쥐 = '쓰레기 3개 줍기' 5회, 벌 = 꽃 단계 + 벌 카드 원문 열기

## 지구 마을 규칙

- 퀘스트는 게임 안 행동이 아니라 **실제 실천 기록**으로만 채워진다. 보상은 직접 '받기'를 눌러 받는다.
- 아이템 12종: 기본 4종, 섬 단계로 열리는 3종, 리사의 부탁으로 열리는 5종(분리수거함·자전거 거치대·새집·작은 도서관·태양광 지붕).
- 놓은 개수 0·4·10·18개에서 섬이 4×4 → 5×5 → 6×6 → 7×7로 넓어진다. 한 번 넓어진 섬은 줄지 않는다.
- 치운 물건은 나뭇잎을 전부 돌려준다. 마을은 시들지 않고 순위·벌점이 없다.
- 닌텐도 '동물의 숲'은 '아늑한 섬 꾸미기' 컨셉만 참고했다. 이름·그림·문구는 쓰지 않는다.
